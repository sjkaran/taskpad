A minimalist, offline task management tool built in Python, designed to be as simple and reliable as a notepad.

## Overview

TaskPad is a lightweight, command-line task manager that helps you organize your daily tasks with ease. Store tasks offline in a JSON file, assign tasks for today or tomorrow, update their status, add remarks, or clear them when done—all with a clean, intuitive interface. Perfect for users who want a no-frills, dependable tool for task management.

## Features

- **Assign Tasks**: Add tasks for today or tomorrow with a simple input process.
- **Update Tasks**: Mark tasks as completed or add remarks to track progress.
- **View Tasks**: Display all tasks organized by date in a clear format.
- **Clear Tasks**: Manually delete tasks with confirmation for safety.
- **Offline & Reliable**: Stores data in a JSON file, ensuring portability and no external dependencies.
- **Minimalist Design**: A clean, notepad-like experience with a focus on functionality.

## Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/yourusername/taskpad.git
   ```

2. Navigate to the project directory:

   ```bash
   cd taskpad
   ```

3. Ensure Python 3.8+ is installed:

   ```bash
   python --version
   ```

4. Run the application:

   ```bash
   python main.py
   ```

## Usage

Launch TaskPad and choose from the following options:

1. **View Tasks**: See all tasks organized by date.
2. **Assign Tasks**: Add new tasks for today or tomorrow.
3. **Update Tasks**: Mark tasks as completed or add remarks.
4. **Clear Tasks**: Remove tasks with confirmation.
5. **Exit**: Close the application.

Example:

```bash
$ python main.py
----------------------------------------
 TASK MANAGER
----------------------------------------
Choose an option:
1. View Tasks
2. Assign Tasks
3. Update Tasks
4. Clear Tasks
5. Exit
```
